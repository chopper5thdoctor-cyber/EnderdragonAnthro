# screenshots

Shots worth keeping. Not documentation — the README and DESIGN.md are that.
This is the mod actually running, which is a different kind of evidence.

## jean-in-her-own-fire.png

Jean in dragon form, standing in a field of her own dragonfire, seen from a
second player's client on a local server.

Worth keeping for what it is a picture of as much as for how it looks. Almost
everything in this mod is drawn on the player it belongs to, and for a long
time every one of those things had only ever been looked at from inside that
player's own head. This is the other side: the form, the wings, the tail, the
purple fire and the name plate, all as somebody ELSE sees them.

That view is also what found three bugs the first-person one could not.
The dragon used to blink out of existence when the viewer looked slightly
away, because Minecraft culls on the bounding box and the wings overhang it by
five blocks a side. The wingbeat only ever played in the head of whoever
pressed the key. And a dragon in creative had no pick-up switch at all.

Taken with `run.bat`, which puts up a server and two clients for exactly this.
